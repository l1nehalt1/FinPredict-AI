FinPredict AI — 1000 клиентов, администратор, годовая история и ML-прогноз

В архиве одна папка FinPredict_AI. Распакуйте её целиком.

Первый запуск Windows:
1. Должны быть установлены SQL Server, ODBC Driver 18 и Python 3.11+.
2. В backend/config.py укажите свой сервер. По умолчанию .\SQLEXPRESS
   и база FinPredictAI_Demo. Если нужна другая база, измените DATABASE_NAME
   или DB_DATABASE в backend/.env. Учётная запись SQL должна иметь права
   создания базы/таблиц и записи данных.
3. Запустите START_WINDOWS.bat. Он установит зависимости в .venv, создаст
   недостающие таблицы и импортирует 1000 клиентов и 423 087 операций.
4. При первом запуске в терминале задайте два пароля (8–128 символов):
   - пароль администратора;
   - общий пароль для синтетических демонстрационных клиентов.
   При вводе пароля символы не отображаются — это нормально.
   Сохраните эти пароли у себя. Готовые пароли в ZIP не записаны.
   Импорт и хеширование 1000 паролей может занять несколько минут.
5. Откройте http://127.0.0.1:8000.
   Администратор: admin@finpredict.local + выбранный пароль администратора.
   Демо-клиент: client0001@example.test + выбранный пароль демо-клиентов.
   Доступны также client0002@example.test ... client1000@example.test.

Повторный запуск сохраняет существующие данные и не дублирует клиентов.
Обычная регистрация тоже работает: новый пользователь получает отдельный
пустой счёт с балансом 0 ₸ и без операций. Роль администратора через регистрацию
получить нельзя. Администратор видит всех клиентов, обычный пользователь —
только свои счета. Администратор просматривает данные без изменения операций.
Если существующая учётная запись с email администратора имеет роль клиента,
скрипт не повысит её права: укажите другой FINPREDICT_ADMIN_EMAIL.

Ручной запуск из папки FinPredict_AI:
  python -m pip install -r backend/requirements.txt
  python backend/app.py

Сервер автоматически вызывает импорт при запуске в терминале. Для отдельного
импорта без запуска сайта: python backend/init_demo.py.
Для запуска через WSGI сначала импортируйте данные этой командой.
Чтобы пропустить автоматический импорт: FINPREDICT_BOOTSTRAP_DEMO=no в .env.
Для запуска без вопросов можно локально задать FINPREDICT_ADMIN_PASSWORD
и FINPREDICT_DEMO_PASSWORD. Не отправляйте .env и backend/.session-secret другим.

Данные:
- 1000 синтетических клиентов и отдельный аккаунт администратора.
- 423 087 доходных/расходных операций с 08.10.2025 по 07.10.2026.
- Имя, демонстрационный email, город, возраст, профессия, сегмент,
  месячный доход, начальный баланс и номер демонстрационного счёта.
- Все сведения искусственные. Связи с настоящим банком нет.
- backend/data/clients_1000.jsonl.gz — сжатые записи для импорта.
- backend/data/manifest.json — описание и количество записей.

Кабинет администратора:
- список всех клиентов, поиск по имени/email/городу, страницы по 25 клиентов;
- число клиентов и операций, суммарный баланс и расходы;
- профиль клиента, его операции, графики доходов/расходов;
- прогноз на 30, 60, 90, 180 и 365 дней, ожидаемый баланс;
- описание модели и показатели проверки на синтетическом месяце.

Модель:
HistGradientBoostingRegressor из scikit-learn 1.8.0. Использует прошлые месячные
переменные расходы, скользящие средние и сезонность. Обучена на 7000 примерах
до августа 2026, проверена на 1000 примерах за сентябрь 2026. Временное разделение
сохраняется; будущие фактические траты не включаются в обучающие признаки.
Ближайшие 365 дней — прогноз с 08.10.2026 по 07.10.2027, а не заранее известные
расходы. Регулярные платежи/доходы добавляются отдельно. Недостающая история
обрабатывается статистической моделью. Годовая точность отдельно не проверена;
диапазон неопределённости иллюстративный, не статистический доверительный интервал.

backend/model/expenses.joblib — готовая обученная модель.
backend/model/metrics.json — показатели валидации (только синтетические данные).
Пересоздание данных: python backend/generate_dataset.py.
Переобучение: python backend/train_model.py, затем перезапуск сервера.

Интерфейс на русском, қазақша и English. Готовая сборка уже находится в dist-mssql.
Node.js не нужен для первого запуска. Для правок интерфейса: pnpm install,
затем pnpm run build:mssql (Node.js 22.13+).

Проверки:
  python tests/test_admin.py
  python tests/test_init_db.py
  python tests/test_finance.py
  node tests/check_languages.mjs
Импорт 1000 клиентов, HTTP-авторизация и права доступа проверены тестовым SQL-
адаптером; инициализация схемы — имитацией ODBC. Живой SQL Server и браузерный
просмотр в среде подготовки недоступны. Проверьте запуск на своём Windows.

Прежняя размещённая версия chatgpt.site этим ZIP не обновляется. Используйте
локальный backend/app.py. Исходники старой D1/Workers-версии сохранены для справки.
Для временного доступа в интернете оставьте сервер включённым и в другом
терминале запустите скачанный cloudflared.exe:
  .\cloudflared.exe tunnel --protocol http2 --url http://127.0.0.1:8000
Для сервиса, доступного только по HTTPS, задайте FINPREDICT_COOKIE_SECURE=yes.
Для локального HTTP оставьте no. Пароли хешируются; сессии отзываются при выходе;
изменения требуют CSRF-токен. Ограничитель входа работает в памяти одного процесса.
Подтверждение email и восстановление пароля в эту учебную версию не включены.
